## 0.1.0-draft.1 - 2026-09-17

### Added

- Eight consolidated design-system planning parts.
- Decision register D01-D45 and additional rule X01: no colored side accent strips.
- Portable KUDU Product UI skill with progressive reference loading.
- English documentation, agent instructions, implementation/review templates, and local helper scripts.
- Draft tokens preserving the discussed brand, neutral, geometry, typography, and motion values.
- Intranet, operational, and engineering pilot briefs and an unexecuted skill-evaluation suite.

### Explicit limitations

- No production component package or validated prototype is claimed.
- Exact semantic status colors, overlay shadows, icon library, fonts, and some layout details are unresolved.
- Known weak draft contrast pairs must not be used for normal active text without remediation.
- Source PDF and font binaries are intentionally not redistributed.

### Repository organization

The self-contained skill folder holds the canonical references and assets. Root documentation and token files point to it to avoid hand-maintained duplication.
