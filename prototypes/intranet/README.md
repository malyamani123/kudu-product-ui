# Pilot A: KUDU Intranet

Status: NOT IMPLEMENTED. Use one real existing Intranet page once its source or an authorized screenshot is provided. The local WSL path discussed previously is not a source file accessible through this repository.

## Task

Help employees find announcements, news, events, useful resources, and the next relevant action. Do not turn the homepage into an administration dashboard.

## Composition candidate

Top or hybrid navigation; a simple heading; one important announcement; editorial news/content area; events and useful resources. Images may be appropriate when actual content calls for them. Do not fabricate KPI cards or place every section inside a card.

## Required evidence

Compare current and proposed composition; inspect actual typography, outline primary action, warm neutrals, spacing, icon consistency, reading width, and mobile navigation. No colored side accent lines, including on announcements.

Test long headlines, no news, no events, loading, inaccessible resources, keyboard navigation, mobile reflow, and Arabic/RTL. Preserve existing links, permissions, content semantics, and behavior. Label synthetic fixtures explicitly.

## Acceptance

The employee can locate a resource and read an announcement without unnecessary navigation. It feels like the same KUDU family as the other pilots without looking like their table workspace. Brand and usability review remain pending until real evidence is recorded.
