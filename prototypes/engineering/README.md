# Pilot C: Engineering project workspace

Status: NOT IMPLEMENTED. Start from an authorized project brief, not invented operational facts.

## Task

Understand a project's current stage, locate the current document version, and see required review or approval actions.

## Composition candidate

Project-centered summary with status, owner, phase, and milestone; sections for a short detail view; tabs only when document, design, approval, and history groups have enough independent content. Use a timeline only when temporal relationships matter.

## Required evidence

Current versus historical file versions, missing preview, long filenames, approval states, permission differences, upload errors, full-width drawing/document area when justified, and mobile preservation of essential actions.

A diagram, map, or drawing view may need a specialized local component. It must still use KUDU control, focus, and status rules; it must not force unrelated Intranet or Finance pages into the same layout.

## Acceptance

An employee can identify the current version and next responsible action. The composition differs from the operational table and Intranet homepage while sharing typography, controls, states, spacing, and restrained brand use.
