# Quick start

1. Read the [installation guide](INSTALLATION.md).
2. Install the portable skill in the actual product repository.
3. Ask the agent to use `kudu-product-ui` and inspect the real project.
4. Review one representative screen before expanding the implementation.
5. Resolve draft token/asset gaps and validate actual behavior.

Start with this request:

```text
Use the kudu-product-ui skill. Review this project's current UI and source.
Preserve all working behavior. Apply the approved KUDU foundations and choose
composition based on this product's tasks, not a generic dashboard template.
Propose one representative screen and list missing assets or components before
coding. Never use colored side accent strips.
```

The complete planning content is indexed in the [documentation map](README.md).
The [validation report](VALIDATION-REPORT.md) distinguishes completed tooling
checks from untested UI behavior. This is a usable skill and design specification,
not a published React component package.
