# Approved KUDU logo assets

The original owner-supplied files are bundled here without modification:

- `kudu-logo-vertical.png` — stacked Arabic/English logo for tall or narrow placements (2753 × 4000 px).
- `kudu-logo-horizontal.png` — horizontal Arabic/English logo for headers and wide placements (4000 × 2164 px).
- `kudu-favicon.svg` — 32 × 32 inverted-triangle application icon with `#F4B21B` fill. Install it at `src/app/icon.svg` where that application convention is used.

Use the supplied logo artwork, not text, recreated vectors, or generated substitutes. Preserve its aspect ratio and the clear-space requirement described in [the foundations](../../references/01-foundations.md). These PNGs are the supplied approved files; request a source vector only when a product needs one. The favicon is an explicit owner-provided SVG specification, not a replacement for the full logo.
