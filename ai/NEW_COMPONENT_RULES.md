# New component rules

Try reuse, then composition, before proposing a new shared component. A one-off product capability may remain local while following the same foundations.

Use the [proposal template](../.agents/skills/kudu-product-ui/assets/templates/component-proposal.md). Describe the unmet need, existing alternatives, reusable API, tokens, states, responsive/RTL behavior, interaction semantics, tests, and migration effects.

Do not silently add new button variants, icon libraries, colors, or radii. Follow the [governance process](../.agents/skills/kudu-product-ui/references/07-governance.md).
