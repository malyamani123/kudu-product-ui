# KUDU UI rules

Use the [skill entrypoint](../.agents/skills/kudu-product-ui/SKILL.md) and the [AI design contract](../.agents/skills/kudu-product-ui/references/04-ai-contract.md). Those are canonical, not duplicated here.

Before designing, identify the product type, user's task, important information, primary action, existing stack, available brand assets, and actual navigation needs. Reuse components and tokens; adapt composition; preserve working application behavior.

Never use colored side accent strips. Never invent a new font, yellow primary button, dashboard, KPI, chart, or chat interface merely to make a page look designed.
