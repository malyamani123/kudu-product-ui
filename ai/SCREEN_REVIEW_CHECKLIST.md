# Screen review checklist

Use the [review report template](../.agents/skills/kudu-product-ui/assets/templates/screen-review.md) and [validation specification](../.agents/skills/kudu-product-ui/references/06-validation.md).

Record each check as PASS, NEEDS REVISION, NOT TESTED, or NOT APPLICABLE. Evidence is required for PASS.

Review the main task, hierarchy, actual components, fonts, spacing, primary/secondary contrast, states, data density, minimal cards, absence of side strips, responsive behavior, RTL, keyboard interaction, and relevant accessibility criteria. Distinguish source-code inspection from a browser test. Do not label an image or static HTML sample WCAG compliant.
